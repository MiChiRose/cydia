# Product

## Register

product

## Users

People browsing MiChiRose packages in Cydia on legacy iPhones. The current design scope is the Weather depiction on a 320-pixel iPhone 4s running iOS 6.

## Product Purpose

Explain what the tweak restores, establish compatibility, and help the reader install it. Cydia supplies installation controls. No technical knowledge should be required.

## Brand Personality

Familiar, calm, practical. The user chose classic Cydia / iOS 6 over a contemporary landing page.

## Anti-references

No marketing hero, decorative animation, diagnostic transcript, dense release history, duplicate install controls, or extra app promotion. This concerns Weather, not the separate Telegraphica presentation.

## Design Principles

- Fit beside Cydia's native interface.
- Lead with the restored stock Weather experience.
- Keep installation instructions actionable.
- Describe tested compatibility honestly.
- Keep implementation history in source documentation.
- Package display names omit the developer nickname: Weather Fix, AirPods Fix. Author credits and the MiChiRose repository identity remain separate.

## Accessibility & Inclusion

Readable system fonts, high contrast, meaningful headings and links, keyboard focus, large tap targets. Support 320-pixel screens and iOS 6 WebKit without JavaScript, external fonts, modern layout dependencies, or motion.
