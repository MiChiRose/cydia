# Актуальные артефакты Cydia

Владелец требует удалять временные файлы и заменённые сборки после работы.
В текущей ветке держать только пакеты из `Packages`, соответствующие текущие
исходники твиков, актуальную IPA и необходимые файлы репозитория.

При публикации сначала обновить пакет, его описание и ссылки на исходники,
затем выполнить `python3 scripts/maintain_repo.py --prune` до коммита.
Команда удаляет заменённые сборки и обновляет индексы и контрольные суммы.
Проверить сохранность остальных пакетов и загрузку опубликованных файлов.
Временную подготовку выполнять в системном временном каталоге и удалять
после проверки. Историю Git не переписывать.
