MiChiRose Weather

Alpha 6 · 0.1.0~alpha6. Только исправление штатной «Погоды», без дополнительного приложения и иконки. Погодная библиотека побайтно совпадает с рабочей Alpha 5: на iPhone 4s / iOS 6.1.3 подтверждён прогноз в Local Weather. Чистая установка Alpha 6 через Cydia ещё проверяется.

Штатная «Погода» получает данные напрямую от Open-Meteo. Собственный сервер и API-ключ не нужны. Пакет требует jailbreak и Cydia Substrate.

Исправление Alpha 5: после удаления WeatherX в настройках может оставаться его адрес сервиса. Теперь запросы на этот точный адрес тоже перехватываются локально и обслуживаются нашим адаптером. Настройки GPS и список городов не меняются.

Исправления Alpha 4: устранено падение загрузчика iOS 6 из-за несовместимых импортов и ARM-стабов. Встроенный Mbed TLS обеспечивает современные шифры для Open-Meteo с проверкой имени и сертификата сервера. Системные сертификаты не меняются. Исправление упаковки LICENSE.dpkg-new сохранено.

Без дополнительной иконки — Alpha 6

Weather Check больше не входит в пакет. После установки пользуйтесь только штатным приложением «Погода». При обновлении через Cydia прежнее приложение, установленное этим пакетом, удаляется автоматически.

Первая проверка

  1. Удалите WeatherX / Weather & Stocks из Cydia. MapsX можно оставить.
  2. Установите MiChiRose Weather (Alpha).
  3. Полностью закройте и заново откройте «Погоду», проверьте Local Weather.
  4. Удалите один старый город в «Погоде» и добавьте его заново через поиск: старые Yahoo ID не подходят.
  5. Проверьте прогноз для вручную добавленного города.

Ожидаемый результат: текущие условия, шесть следующих дней и двенадцать следующих часов. Переключение °C/°F и внешний вид нужно проверить на телефоне.

Ограничения

Системный Core Location не меняется: штатная Local Weather получает прогноз по уже доступному местоположению. Виджет, Siri и «Акции» не входят в эту alpha. HTTPS-клиент ограничен погодными API и использует встроенные корни ISRG X1/X2. При смене CA может потребоваться обновление пакета. Проверка сертификатов не отключается.

Если погода не загружается, включённая в пакет утилита поможет определить причину:

michirose-weather-probe --live Minsk

Удаление пакета убирает исправление. После удаления можно вернуть WeatherX. Системное приложение и список городов автоматически не изменяются.

Источники данных

Прогноз: Open-Meteo. Города: GeoNames через Open-Meteo. Данные CC BY 4.0; наш адаптер округляет температуры и преобразует значки и формат ответов. Бесплатный API — для некоммерческого использования.
