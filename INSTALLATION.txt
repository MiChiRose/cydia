Update over the existing app; do not delete it. No terminal/computer needed.
The same app identity, container-preservation check and Keychain identity remain.
If an old half-configured warning appears, use Ignore (Temporary), refresh and
upgrade; do not forcibly clear packages.

New icon-refresh request is bounded and nonfatal: unsupported system API cannot
turn a successful app update into a half-installed package. A diagnostic code
OWN_ICON_REFRESH_RESULT is printed in the Cydia log. Acceptance by the system API
does not prove visible Home-screen refresh; physical appearance is still pending.
No global cache deletion, app registration rebuild or SpringBoard restart is used.

Requires jailbroken iOS6/ARMv7 and compatible AppSync Unified from a trusted source.
Stock iOS is unsupported. IPA requires a compatible jailbreak installer, not just
Safari download: Telegraphica-0.1.0-beta1-build41-ios6-armv7.ipa.

Packages contain no accounts, sessions, messages, contacts, databases, cache,
API credentials, signing keys or profiles. Every user logs in independently.
Real calls/proxy settings are not implemented; Music search has known issues.
Background reception uses the existing jailbreak companion; battery behavior is
experimental. Send feedback without passwords/codes/phone numbers/chat contents.
