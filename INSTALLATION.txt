Telegraphica 0.1.0 beta 1 — build 38, Cydia revision 0.1.0~beta1-38.5

Installer38.5 and Background25 address dependency configuration exit status3
before the app installer starts. Missing app/deferred background discovery no
longer blocks the full package; stale jobs are not loaded. Invalid unrelated
application metadata no longer blocks Telegraphica discovery.
The application remains build38; its IPA and notification worker are unchanged.

Refresh Cydia sources and select Telegraphica0.1.0~beta1-38.5; companion25
updates automatically. If Cydia offers to retry an old half-configured package,
choose Ignore (Temporary), refresh and upgrade Telegraphica. Do not forcibly
clear packages or delete the existing app.

Requires jailbreak and AppSync Unified compatible with iOS6.
App was tested on iPhone4s/iOS6.1.3; the previous38.3 Cydia update preserved
login.38.4 first installation failed before the app installer ran. This38.5
revision has native synthetic package-order and iOS6.1 discovery checks;
first installation THROUGH CYDIA on a physical device is still unverified.
Other ARMv7 devices have not yet been verified.

Cydia: Manage > Sources > Edit > Add:
https://michirose.github.io/cydia/
Refresh, select Telegraphica (full application), Install.
Telegraphica Background is installed/configured automatically. No terminal needed.
AppSync must already be available from your trusted package source.
Open the app and log in to your own Telegram account.

Do NOT delete an existing app before updating. Removing the Cydia installer
package preserves the app/account; deleting its Home-screen icon may erase data.
IPA alone requires a compatible jailbreak IPA installer with AppSync.
Safari downloading an IPA is not an installation method. Stock iOS is unsupported.

The packages include no session, messages, contacts, cache, database keys,
signing keys, provisioning profiles or embedded local Telegram API configuration.
Application configuration is obtained over HTTPS. Every user logs in independently.

Real calls and in-app proxy settings are not implemented. Music search has known
issues. Background notifications use a jailbreak companion; battery behavior is
experimental. Send feedback with build/device/iOS/steps/error, without private
chat contents, phone numbers, codes or passwords.
